# Real Life Practice (archivado 2026-10-03)

"Con una persona": tarjeta ancha y baja para conversar con alguien real
(LO QUE ENTENDÍ / MI TURNO / respuestas sugeridas).

Se archivó porque la Spectacles aplica *Bystander Speech Rejection* cuando la
Lens usa el ASR de Snap: el micrófono no capta bien a otras personas.
Probado en device: la voz ajena llegaba 25-50x más baja.

Contenido: copias de LingoSpaceLiveCaptionUI.ts y de LingoSpaceMain.ts /
LingoSpaceTalkService.ts tal como estaban con esta función conectada
(openFaceToFace, finishFaceToFaceVoice, interpretEcho, checkMine), más el arte
REAL LIFE. Idea para retomarlo: usar el celular (app iOS) como micrófono.
